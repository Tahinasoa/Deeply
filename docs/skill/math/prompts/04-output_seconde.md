# 2 — Nombres et calculs numériques

## Je dois être capable de…

- skill : utiliser les notions de multiples, de diviseurs et de nombres premiers
- skill : calculer une expression numérique en utilisant les règles de calcul sur les puissances
- skill : calculer une expression numérique en utilisant les règles de calcul sur les quotients

### Démonstrations
- skill : démontrer qu'un quotient donné n'est pas un nombre décimal
- skill : démontrer qu'une racine carrée donnée est irrationnelle
- skill : démontrer que, pour une valeur numérique donnée d'un nombre, la somme de deux multiples de ce nombre est un multiple de ce nombre
- skill : démontrer que le carré d'un nombre impair est impair
- skill : démontrer que, quels que soient les réels positifs a et b, la racine carrée d'un produit est égale au produit des racines carrées

### Algo & Prog
- skill : déterminer si un entier naturel est premier
- skill : déterminer par balayage un encadrement d'une racine carrée d'amplitude inférieure ou égale à une précision donnée

- skill : déterminer le plus grand multiple d'un entier naturel inférieur à un autre entier naturel donné
